# ChatGPT Voyager

用于 ChatGPT 网页端的问题导航、对话导出和公式复制，支持 Chrome、Edge。

## 安装

1. 下载 [v0.4.0 安装包](https://github.com/121209/chatgpt-voyager/releases/download/v0.4.0/chatgpt-voyager-v0.4.0.zip)，解压到固定文件夹。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 打开或刷新 [ChatGPT](https://chatgpt.com/) 对话页，在页面右侧找到 Voyager 菜单。

更新时，将新文件替换到原加载目录，点击扩展的“重新加载”，再刷新 ChatGPT 页面。改用新目录时先禁用旧版。

## 使用方法

### 问题导航

打开页面右侧 Voyager 菜单，进入“目录”。输入关键词搜索，点击问题跳转；每个问题下方显示回答的一句话概览。长对话有遗漏时，滚动加载历史内容或点击“深度采集完整对话”。拖动面板边缘可调整大小。

### 对话导出

打开“导出”，选择模式并勾选内容：

- **问题**：仅导出已记录的问题清单。
- **对话**：导出当前页面已加载的提问和回答；历史回答请先滚动加载，并核对列表。

点击“复制 Markdown”“导出 Markdown”“导出 PDF”或“导出图片”。PDF 在打印预览中保存，图片下载为 PNG；内容较多时分批导出，截图时保持 ChatGPT 标签页处于活动状态。

### 公式复制

悬停数学公式或选中公式文本，点击“复制公式”，选择格式：

- **Word UnicodeMath**：在 Word 中按 `Alt+=` 打开公式编辑器后粘贴。
- **WPS LaTeX**：在 WPS 的 LaTeX 公式输入中粘贴。
- **Markdown LaTeX**：复制带公式分隔符的 LaTeX。
- **原始 LaTeX**：复制不带外围分隔符的 LaTeX。

### 会话文件夹

点击浏览器工具栏的插件图标，新建文件夹，点击对应文件夹的“Save”保存当前会话链接。

### 提示词与设置

在插件弹窗中调整默认打开面板、自动刷新等设置；点击“Options”可新增或删除提示词。提示词目前仅支持本地管理，文件夹、提示词和设置保存在当前浏览器中。
